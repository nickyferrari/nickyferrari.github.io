DEPI Machine Backups

Privacy policy

This policy describes the private Google Drive backup utility operated by Nicholas Ferrari. It is not a public backup service.

Effective October 29, 2026

Data & purpose

The utility reads selected local project files and uploads copies to the operator’s Google Drive for backup and access from other computers. These may include presentations, model resources and source code, documentation, generated outputs, and verification records.

Through the Drive API it accesses the contents and metadata of files and folders authorized for this app, including file names, identifiers, sizes, and available checksums. This information is used to create dated snapshots and verify transfer integrity. Local manifests and transfer logs record file names, source locations, checksums, and backup results.

The utility does not request Gmail, Calendar, Contacts, or unrestricted Drive access. It does not sell Google user data, use it for advertising, or use it to train AI models.

Access & storage

Google OAuth authorization requests the https://www.googleapis.com/auth/drive.file scope. This limits access to Drive files and folders created by or explicitly made available to this app. Google handles account sign-in. The backup script does not collect the account password.

OAuth credentials and tokens are stored locally with owner-only file permissions. They are excluded from the backup selection and are not published on this website. Communication with the Google Drive API uses HTTPS. Local snapshots and verification records are stored on the source computer. Uploaded snapshots are stored in the operator’s Google Drive under that account’s access controls.

The utility does not create public-sharing permissions or send backup contents to third parties other than Google for storage. Access by the operator on another computer is governed by the Google account and its Drive permissions.

Retention & control

Snapshots are retained until the operator deletes them. No automatic retention pruning is currently configured. Stopping the schedule or revoking access does not delete existing local or cloud copies.

The operator can stop scheduled backups locally, remove local snapshots and credentials, and delete cloud snapshots through Google Drive. Access can be revoked in Google Account third-party connections. Revocation prevents future authorized API access after any already-issued access ceases to be valid. Existing Drive files remain until deleted by the owner.

This website

These public information pages are hosted on GitHub Pages. They do not contain backup files, OAuth credentials, or private research data. These pages add no analytics, advertising trackers, sign-in forms, or cookies. GitHub may process standard hosting and access information under its privacy statement.

Contact & changes

This policy will be updated here if the utility’s data practices change. Its use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
